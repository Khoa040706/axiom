## Hướng dẫn chụp screenshot

1. Chạy app: `npm run dev` trong thư mục `axiom/`
2. Đăng nhập lần lượt với các tài khoản theo role
3. Chụp bằng **Windows Snipping Tool** (Win + Shift + S) hoặc **DevTools** (Ctrl+Shift+P → "Screenshot")
4. Lưu vào thư mục `bao-cao/hinh-anh/` với tên file theo quy ước ở trên
5. Kích thước đề xuất: **1920×1080** (Full HD), crop phần browser chrome
